# TowerScanner + اتصال

نسخة مبنية من الصفر مستوحاة من TowerScanner v8 (ماسح الأبراج)، مع إضافة قسم
«الاتصال» الذي طلبه المستخدم:

- يعرض الأبراج الخلوية القريبة والبرج المتصل حالياً: Cell ID / Base Station Id
  و LAC / TAC و PCI وقوة الإشارة، مع تحديث تلقائي.
- زر «📌 ثبّت هذا البرج للاتصال» في الشاشة الرئيسية، أو من إعدادات الاتصال،
  لتثبيت البرج الحالي الذي تتم عليه الأتمتة.
- إعدادات الاتصال: إضافة رقم وحفظه، مدة المكالمة الصادرة بعد الرد بالثواني،
  ومدة الرد على المكالمة الواردة بالثواني.
- الأتمتة: يتصل التطبيق بالرقم فقط أثناء وجود الهاتف على البرج المثبّت،
  ويبقى في المكالمة المدة المحددة ثم يفصل ويعيد الاتصال.
- إذا تغيّر البرج أثناء المكالمة، يفصل فوراً، ويعاود الاتصال عند العودة
  للبرج المثبّت.
- المكالمة الواردة من الرقم نفسه: لا تُجاب إلا على البرج المثبّت، وتبقى
  المدة المحددة ثم تفصل.

ملاحظة: بدء المكالمة الصادرة يستخدم ACTION_CALL ويتطلب منح إذن
CALL_PHONE. إنهاء المكالمة والرد على المكالمات الواردة ما زالا يعتمدان
على خدمة الوصول المفعّلة، وقد تختلف أزرار تطبيق الهاتف بين الأجهزة.
على بعض إصدارات أندرويد/الشركات المصنّعة قد تُقيّد هذه العمليات.

البناء عبر GitHub Actions (`.github/workflows/build-apk.yml`) وينتج
`app-debug.apk`.
